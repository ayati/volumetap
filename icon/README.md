# volumetap アイコン（決定稿）

背景色 `#1E88D8` / 白グリフ。2026-07-23 確定。

ドラフト（`../icon_for_volumetap_draft03.png`）から以下を変更した。

- **ロングシャドウを削除** — ランチャーがアダプティブアイコンに独自の影を付けるため二重になる。
  また円形以外のマスクでは影が斜めに断ち切られて破綻する
- **円の輪郭を削除し、背景を単色ベタに** — マスク形状はランチャー依存で、円形とは限らない。
  円形マスク環境では二重円に、角丸四角マスク環境では円が浮いて見える
- **グリフをセーフゾーンに収めた** — 内容の外接は中心から半径 33dp 以内。
  アダプティブアイコンの中央 66dp 円に収まる
- **背景色を濃くした** — `#74C0EE`（ドラフト）→ `#1E88D8`。
  白とのコントラスト比 約 2.4 → 約 3.8。48dp 表示で細い線が飛ぶのを防ぐ

## ファイル

### プロジェクトに入れるもの

`icon/res/` 以下をそのまま `app/src/main/res/` へコピーする。

| パス | 内容 |
|---|---|
| `res/drawable/ic_launcher_foreground.xml` | 前景レイヤー（白グリフ・ベクター） |
| `res/drawable/ic_launcher_monochrome.xml` | モノクロレイヤー（Android 13+ テーマアイコン） |
| `res/mipmap-anydpi-v26/ic_launcher.xml` | アダプティブアイコン定義 |
| `res/values/ic_launcher_background.xml` | 背景色 `#1E88D8` |

ベクターで持つため、密度別 PNG（`mipmap-hdpi` 等）は不要。

### プレビュー・ストア用

`python3 icon/build_icon.py` で再生成できる。

| ファイル | 用途 |
|---|---|
| `preview/preview_sheet.png` | 円マスク / 角丸マスク / 48dp 実寸 の並び |
| `preview/masked_circle.png` | 円形マスク適用時の見え方 |
| `preview/masked_squircle.png` | 角丸四角マスク適用時の見え方 |
| `preview/adaptive_full.png` | マスク前の 108dp 全面 |
| `preview/ic_launcher_foreground_432.png` | 前景レイヤーのラスタ版 |
| `preview/play_store_512.png` | **Play ストア用** 512x512・不透明・影なし・角丸なし |

## 幾何仕様

108dp ビューポート。ストローク幅 3.4dp（タップ波紋のリングのみ 3.0dp）。

| 要素 | 座標 |
|---|---|
| ボリュームロッカー | (29,33)-(45,75)、角丸 8 |
| スマートフォン | (57,35)-(79,73)、角丸 3.5 |
| ロッカー中央のドット | 中心 (37,54)、r=4.2、塗り |
| ＋ / − | 中心 (37,42.5) / (37,65.5)、腕長 4.0 |
| 接続線 | (40,54)-(61.4,54) |
| タップ波紋 | 中心 (68,54)、リング r=6.6 / 中心 r=2.6 |

変更する場合は `build_icon.py` の定数と `res/drawable/*.xml` のパスデータの
**両方**を更新する（両者は独立に持っているため、片方だけ直すとずれる）。
